# PONDASHI — 音声ポン出し

ブラウザで動く、日本語の音声ポン出しアプリ。サーバーへの音声アップロードはありません。

## 起動

Node の追加パッケージやビルドは不要です。Python 3 のある環境で:

```sh
git clone https://github.com/yamadesu46/pondashi.git
cd pondashi
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開いてください。`index.html` を直接開くのではなく、HTTP サーバーを利用します。静的ホスティングにもそのまま配置できます（HTTPS 推奨）。

## 機能・操作

- タブで複数ボードを切り替え。各ボードはボタン12個から開始し、追加可能。切り替えても再生は継続。
- 空ボタンをクリックして音声を選ぶか、音声ファイルをドロップ。
- 押すと再生、もう一度押すと停止。
- 各ボタンの設定から名前、色、音量（0〜100%）、リピート、フェードイン・アウト（0〜60秒）を指定。
- **重ねる:** 他のボタンの音を継続。
- **割り込み:** 他の音を即停止して再生。停止中のフェードも打ち切ります。
- **全て停止 / Esc:** 全ボードの音声を指定秒数（0〜60秒）でフェードアウト。0秒で即停止。
- 全体音量、再生進捗、音声・設定を含むJSONバックアップの書き出し・復元（選択中のボード単位）。

フェードインは再生開始時、フェードアウトは同じボタンで手動停止したときに適用されます。フェード中のボタンを再押下しても停止時間は延長しません。自然終端では音声ファイルの終わりで停止します。

## 保存と対応環境

音声と設定は IndexedDB に保存され、同じブラウザ・同じオリジンで再度開くと復元されます。サイトデータ削除やプライベートブラウズ終了で失われる場合があるためバックアップを推奨します。別端末との自動同期はありません。保存容量はブラウザと端末に依存し、容量不足の場合はエラーを表示します。バックアップには音声を含むためサイズが大きくなります。

Web Audio API / IndexedDB 対応の現行 Chrome、Edge、Firefox、Safari を想定。MP3 / WAV / OGG / M4A 等の対応可否はブラウザのコーデックに依存します。音声は再生時にメモリへ展開するため、大容量の音声や多数の同時再生は端末性能に影響します。ページを閉じると停止します。

## 構成・検証

- `index.html` / `style.css`: レスポンシブな操作画面
- `app.js`: ファイル登録、IndexedDB 保存、バックアップ
- `audio-engine.js`: Web Audio による再生、フェード、割り込み

```sh
npm test
```

音声エンジンのテストは Node 標準テストランナーを使用。重ね再生、割り込み、フェード途中の停止、全停止、非同期開始の取消を検証します。実ブラウザのコーデック・端末の音声出力は別途実機確認が必要です。
